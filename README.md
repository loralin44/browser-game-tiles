# browser-game-tiles
# Arkanoid / Breakout
Реализовано на HTML5 + CSS3 + JavaScript с использованием PixiJS.
Попытка повторить классическую игру Arkanoid (Famicom, 1986).

## Ссылка  на игру 
https://loralin44.github.io/browser-game-tiles

## Управление
- **Space** — начать игру / запустить мяч
- **<- / A** — движение платформы влево
- **-> / D** — движение платформы вправо
- **Кнопка Pause** — пауза
- **Кнопка Restart** — перезапуск

## Технологии

- HTML5 (canvas)
- CSS3
- JavaScript (ES-модули)
- PixiJS 8
